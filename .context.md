## 🎯 Domain & Capabilities
- **Platform Intent:** An agricultural/rural services marketplace with two user classes: **Service Providers** (offering equipment, labor, tech) and **Service Seekers** (farmers/clients looking to hire).
- **Auth Gateway:** Firebase Auth SMS OTP, backed by a custom Node.js/TypeScript Express server (`https://backend.barabaricollective.org`). OTP delivery via **Twilio**. File uploads via **AWS S3**.
- **Hardware Dependencies:** GPS tracking (`geolocator ^13.0.2`), native file picking (`file_picker ^8.1.7`), external dialing (`url_launcher ^6.3.1`).

---

## 🏗️ State & Lifecycle Management
- **Framework Core:** **GetX** (`get: ^4.6.6`) — routing, state, and dependency injection.
- **Storage Strategy:** `get_storage: ^2.1.1` for reactive key-value storage; `shared_preferences: ^2.3.4` at the native layer.
- **State Pattern:** Strict view/controller separation. Views in `lib/pages/...` consume reactive state via `Obx(...)`. Controllers in `lib/controller/...` hold all business logic.
- **App Entry:** `main.dart` bootstraps `AuthController` via `Get.put()`, reads saved language from storage, and launches `GetMaterialApp` with Poppins font, dark seed color (`black`), and GetX route table.
- **`home.dart`:** Empty scaffold stub — not wired into routing. Safe to ignore or repurpose.

## 🖥️ Backend Architecture (Node.js/TypeScript — separate repo)

- **Runtime:** Node.js + TypeScript (`src/` → compiled `dist/`)
- **Database:** MongoDB (Mongoose models)
- **OTP Delivery:** Twilio (`src/utils/twilioService.ts`)
- **File Storage:** AWS S3 (`src/utils/s3Upload.ts`, `s3OTPService.ts`)
- **Auth:** JWT (`src/utils/jwt.ts`) — token returned on OTP verify, stored client-side as `StorageKeys.JWT_TOKEN`
- **Middleware:** `authMiddleware.ts` (JWT guard), `multerMiddleware.ts` (S3 file uploads)

# Raithan-ServiceApp

An agricultural marketplace application targeting rural users, service seekers, and machinery/drone owners.

## 🚀 Getting Started

### Prerequisites
- Flutter SDK `^3.5.2`
- Dart SDK configured locally

### Setup & Execution
1. **Fetch dependencies:**
   ```bash
   flutter pub get
Verify connected emulators or physical devices:

Bash
flutter devices
Run the application:

Bash
flutter run
